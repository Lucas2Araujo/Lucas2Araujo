### 🚀 Projetos em Destaque

* **[Hinário Inteligente (NHA_Intel)](https://github.com/Lucas2Araujo/NHA_Intel):** Aplicativo multiplataforma em Python/Flet para consulta offline de hinos e Bíblias. Conta com SQLite/FTS5 para busca rápida, arquitetura em camadas, sistema heurístico explicável de recomendações, testes assíncronos e automação de build CI.
* **[PDI — Processamento Digital de Imagens](https://github.com/Lucas2Araujo/PDI):** Aplicação interativa em Python (Flet, NumPy e Pillow) para análise e transformação de imagens. Implementa K-Means em NumPy, quantização uniforme e por histograma, dithering Floyd–Steinberg, cálculo de métricas (MSE, PSNR, MAE) e processamento em lote.
* **[Kahoot Points](https://github.com/Lucas2Araujo/Kahoot_Points):** Automação em Python via Selenium e Chrome Headless para extração de relatórios e sincronização com Google Sheets via API, contendo rotinas de auditoria e prevenção contra sobrescrita de dados.
* **[App ADM Portuária](https://github.com/Lucas2Araujo/App_ADMPortuaria):** Protótipo acadêmico para gestão portuária com CLI e GUI em Flet, modelagem relacional via SQLAlchemy/SQLite, motor de priorização de atracação por regras de domínio e documentação UML.
